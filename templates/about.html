Project Overview

Smart Face is an advanced AI-powered Attendance System designed for high-security environments. Unlike traditional cloud-based solutions, this architecture runs entirely locally, ensuring sensitive biometric data never leaves the secure server.

The core engine is built on InsightFace (ArcFace), achieving state-of-the-art accuracy in facial recognition. It features a custom-tuned Liveness Detection Layer (Anti-Spoofing) using MiniFASv2 that effectively distinguishes between real human faces and digital or printed spoof attacks by analyzing texture, depth, and edge artifacts.

Fast & Light

Powered by Flask & SQLite for lightweight deployment and fast local execution.

AI Recognition

Powered by InsightFace (ArcFace) for highly accurate facial recognition.

Anti-Spoofing

MiniFASv2 liveness detection prevents spoofing using photos, videos and printed faces.
