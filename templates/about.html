Project Overview

Smart Face is an advanced AI-powered Attendance System designed for high-security environments. Unlike traditional cloud-based solutions, this architecture runs entirely locally, ensuring sensitive biometric data never leaves the secure server.

The core engine is built on InsightFace (ArcFace), achieving state-of-the-art accuracy in facial recognition. It features a custom-tuned Liveness Detection Layer (Anti-Spoofing) using MiniFASv2 that effectively distinguishes between real human faces and digital/printed spoof attacks using analyzing texture, depth, and edge artifacts.
